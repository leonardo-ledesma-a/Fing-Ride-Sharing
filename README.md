# Fing Ride Sharing


## Descripción

Fing Ride Sharing es un sistema de gestión de viajes para estudiantes de la facultad de ingeniería. Fue realizado bajo el paradigma de la orientación a objetos
con el propósito de aprender los conceptos básicos y avanzados del analisis, diseño e implementación de dicho paradigma.

## Tecnologías

- C++

## Cómo compilar y ejecutar

El proyecto cuenta con un Makefile, el comando make help muestra la lista de comandos make disponibles para la compilación y ejecución del programa.

## Funcionalidades

- Permite crear Usuarios de tipo Pasajero y Conductor
- Para los conductores permite registrar vehículos y publicar viajes.
- Para los pasajeros permite generar reservas de viajes
- Los usuarios en general pueden calificar otros usuarios que hayan compartido viaje con ellos.
- Permite cargar un estado concreto al programa con Usuarios, Vehiculos, Viajes, Reservas y Calificaciones.

## Estado del proyecto

Hecho para Programación 4, FING - UdelaR, 2026.
